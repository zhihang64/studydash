关于

这是一个纯静态页面：所有 CSS 与 JS 都内联在同一个 HTML 文件里，不引用任何外部资源，也不会发起任何网络请求。

数据在渲染时已经内嵌进页面，刷新不会重新抓取。要更新请重新运行 python dashboard.py all 后再打开。
